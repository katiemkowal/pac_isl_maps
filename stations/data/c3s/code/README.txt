These functions were developed to download C3S data from the climate datastore (new Beta version - 2024 - make sure to update the cdsapi instruction key to run!), hosted by ECMWF

The config file houses the constants necessary to run the scripts
The helper_functions file includes functions helpful to fun the main script
The retrieve_functions file includes functions written specifically to download data from cds
The download_c3s file imports the above mentioned files and runs the download as a main script
